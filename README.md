A collection of minimalist, high-fidelity logic puzzles built for the modern web. Inspired by the logic games found on LinkedIn and classic puzzle suites, **Mind Games** focuses on smooth interactions, crisp visuals, and brain-teasing challenges.

---

## 🎮 The Games

### ⚡ Zip
The ultimate path-building challenge.
*   **The Goal:** Connect numbered checkpoints in ascending order (1 → 2 → 3...).
*   **The Catch:** You must visit every single cell on the grid exactly once.
*   **Feel the Flow:** Features a "magnetic" path-drawing system with fluid gradients and satisfying visual feedback.

### 👑 Qween
A logic puzzle fit for royalty.
*   **The Goal:** Place one "Queen" in every row, every column, and every colored region.
*   **The Constraint:** No two Queens can touch each other—not even diagonally!
*   **Master the Grid:** Use logic to mark "safe" zones and narrow down the royal positions.

### 🧩 Patches
A colorful test of spatial reasoning.
*   **The Goal:** Fill the board regions according to specific local constraints.
*   **Strategic Filling:** Every choice affects the surrounding patches. Can you solve the pattern?

---

## ✨ Key Features

-   **🎯 Tactile UX:** Optimized for both mouse and touch with "magnetic" snapping and instant backtracking.
-   **🌈 Vibrant Visuals:** Smooth SVG animations, glowing gradients, and polished state transitions.
-   **⏱️ Performance Tracking:** Built-in timer and "Win Record" system to track your progress.
-   **🌗 Dark Mode Ready:** Fully responsive design that looks great in both light and dark environments.
-   **🚀 Lightning Fast:** Powered by **Vite** and **React 18** for a zero-lag experience.

## 🚀 Getting Started

### Prerequisites
-   [Node.js](https://nodejs.org/) (v16.0.0 or higher)
-   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/mind-games.git
    cd mind-games
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
